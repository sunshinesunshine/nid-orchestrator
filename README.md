## 🏛️ The 6-Pillar Sub-Project Standard

Every sub-project governed by Nid adheres strictly to the **6-Pillar Architecture** to eliminate failure modes and enforce 100% execution fidelity:

| Pillar | File | Primary Purpose | Failure Mode Prevented |
| :--- | :--- | :--- | :--- |
| **Pillar 1** | `📌 PROJECT.md` | In-Scope & Out-of-Scope boundaries | Scope creep & unaligned tangents |
| **Pillar 2** | `🛡️ AGENTS.md` | Persona permissions & locked boundaries | Unsanctioned cross-domain edits |

## 🔄 Daily Execution Cycle (6+1 Steps)

```
[ 0. Context Check ] ➔ [ 1. Short Prompt ] ➔ [ 2. Read 6 Pillars ] ➔ [ 3. Locked Execution ] ➔ [ 4. Pre-Close Sync ] ➔ [ 5. Immediate Commit ] ➔ [ 6. Clean Handoff ]
```

1. **Step 0: Context Budget Check:** Recommends `/compact` when turn depth exceeds 15 steps.
2. **Step 1: Short Chat Prompts:** High-level prompts without repetitive context re-explanation.
3. **Step 2: Auto Pre-Read:** Nid and assigned subagents automatically read the 6 Pillars before starting.
4. **Step 3: Locked-Scope Execution:** Agents operate strictly within their boundaries and assigned recipes.
5. **Step 4: Pre-Close Sync:** Checks 3 mandatory points: `SOT Delta` $\rightarrow$ `ROADMAP Tick` $\rightarrow$ `Diary Append`.
6. **Step 5: Immediate File Commit:** Any agreed decision is written to disk immediately.
7. **Step 6: Clean Context Handoff:** Clean session close enabling 100% context resumption across AI models.

## 🛡️ Accuracy Protocol & Unified `/audit`

- **Zero-Fabrication Hard Rule:** Strictly forbids hallucination of DOIs, PMIDs, sample sizes ($N$), $p$-values, odds ratios ($OR$), or hazard ratios ($HR$).
- **Markdown First:** All research drafts and protocols are curated in `.md` for transparent auditing before any on-demand Word (`.docx`) export.
- **Pre-Flight 4-Pillar Deliverable Audit (`deliverable_auditor.py`):**
  - **Pillar 1:** Citation & Claim Grounding (2-Pass PubMed/CrossRef + local PDF verification).
  - **Pillar 2:** Statistical & SOT Triangulation (enforcing Peduzzi rule $\text{EPV} \ge 10$).
  - **Pillar 3:** LaTeX & Layout Invariance (KaTeX formula validation & SHA-256 byte proof).
  - **Pillar 4:** Anti-Slop & Epistemic Rigor (stripping generic AI buzzwords and empty qualifiers).

## 🔄 Automatic Versioning & Auto-Publish Engine

This repository is automatically kept in sync with the live AI Sandbox:
- When changes occur in `AGENTS.md` or Nid specifications, running `./sync_version.sh` (or triggering Nid's Pre-Close Gate) automatically:
  1. Synchronizes updated specifications.
  2. Bumps the semver version in `VERSION`.
  3. Appends milestone changes to `CHANGELOG.md`.
  4. Commits and pushes to `origin main`.
  5. Triggers GitHub Actions to update GitHub Pages automatically.
