🏛️ 6-Pillar Sub-Project Architecture

ทุกโปรเจกต์ต้องมีโครงสร้าง 6 เสาหลักเพื่อป้องกันข้อผิดพลาด 100%:

  • PROJECT.md ขอบเขตงานชัดเจน (In-Scope vs Out-of-Scope)
  • AGENTS.md สิทธิ์และขอบเขตข้อห้ามของเอเจนต์ (ห้ามแตะไฟล์ผิด)
  • SOT.md ความจริงล่าสุด ตัวเลข สถิติ พารามิเตอร์ที่ verify แล้ว
  • ROADMAP.md แผนงาน Phase และรายการ Checklist ความคืบหน้า
  • UX.md รูปแบบผลงานและเกณฑ์การตรวจรับงาน (Acceptance Criteria)
  • graft/ แผนที่โครงสร้างไฟล์ โค้ด และความเชื่อมโยง (Dependencies)

🔄 Daily Execution Cycle (6+1 Steps)

วงรอบการทำงานประจำวันที่แม่นยำและไม่สูญเสียบริบท:

  • 0. Context Budget Check: แนะนำ /compact เมื่อบทสนทนา > 15 steps
  • 1. Short Chat Prompt: รับคำสั่งสั้นกระชับจากคุณหมอ
  • 2. Auto Pre-Read: เอเจนต์อ่าน 6 เสาหลักเองก่อนลงมือทันที
  • 3. Locked-Scope Execution: ทำงานจำเพาะตามขอบเขตและสิทธิ์
  • 4. Pre-Close Sync: ตรวจ 3 จุด (SOT Delta, ROADMAP Tick, Diary Append)
  • 5. Immediate File Commit: ข้อตกลงใหม่ย้ายลงไฟล์ทันที
  • 6. Clean Context Handoff: จบรอบ แชทใหม่ทำงานต่อจากไฟล์ได้ 100%

🛡️ Quality Gate & Accuracy Protocol

มาตรฐานความแม่นยำทางวิชาการและการแพทย์สูงสุด:

  • Zero Hallucination: ห้ามกุ DOI, PMID, Sample size ($N$), ค่า $p$, OR, HR
  • Unified /audit (4 Pillars): ตรวจสอบวรรณกรรม 2-pass, ตรวจสอบสถิติเทียบ SOT, รักษา LaTeX/Layout Invariance (SHA-256) และ Anti-Slop
  • Token Triad: RTK (กรอง Terminal) → Ponytail (โค้ดกระชับ) → Caveman (สรุปเนื้อแน่น)
  • Anti-Slop Filter: กำจัดคำโฆษณา AI, ไอคอนลอย, และคอมเมนต์ขยะ
